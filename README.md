# MultiOs

**MultiOs 0.1.0 "Prism" — an original hobby operating system for x86_64, written from scratch.**

MultiOs is a standalone educational operating system. It contains no Linux, BSD,
Windows, macOS, Android, or other OS kernel, userspace, init, package manager,
desktop, or source code. Only standard open-source *development tools* are used
to build it: GCC, NASM, GNU Make, GRUB (Multiboot2 boot loader, used only to
start the prototype), QEMU (emulator), Python, and Git.

- Architecture: x86_64
- Boot protocol (prototype): Multiboot2 via GRUB
- Emulator: QEMU (`qemu-system-x86_64`)
- Language: C11 (freestanding) + NASM assembly
- License: MIT — see `LICENSE`
- Branding originality: see `BRANDING.md`

## Quick start (Linux / WSL Ubuntu)

Install build tools:

```sh
sudo apt-get update
sudo apt-get install -y gcc nasm make qemu-system-x86 grub-pc-bin xorriso mtools python3
```

Build:

```sh
make
```

Run in QEMU (VGA + serial to stdio):

```sh
make run
# or with curses-free serial log:
make run-serial
```

Expected output on the VGA console and on serial (`COM1`):

```
MultiOs 0.1.0 "Prism" — prismkernel
[memory] map parsed ...
[shell] type `help`
multios>
```

Type `help` for shell commands.

```
  console/serial.c         COM1 driver for logs
  console/kprint.c         kprintf / klog / panic
  cpu/gdt.c                64-bit GDT reload (original descriptors)
  cpu/idt.c                IDT + exception/IRQ dispatch
  cpu/pic.c                8259 PIC remap
  cpu/pit.c                8253/8254 PIT timer, ticks/uptime
  mm/pmm.c                 physical page allocator (bitmap from Multiboot2 mmap)

  input/keyboard.c         PS/2 keyboard, Set-1 translation (own table)
  shell/shell.c            built-in shell: help/clear/info/mem/uptime/echo/logo

```

## Technical notes

- The kernel is freestanding (`-ffreestanding -nostdlib -mno-red-zone`).
  It provides its own `memcpy`, `memset`, `strlen`, etc.
- Paging: the bootstrap creates PML4/PDPT/PD with 2 MiB huge pages
  identity-mapping the first 1 GiB. The prototype stays in this mapping;
  a full virtual-memory manager is roadmap, not yet required to boot a shell.
- Interrupts: PIC remapped to 0x20–0x2F, IDT with 256 gates, PIT 100 Hz,
  keyboard IRQ1 with ring buffer.
- Memory: Multiboot2 memory map feeds a bitmap PMM (4 KiB pages, up to
  4 GiB tracked, allocation only below the 1 GiB identity window for DMA-free
  prototype simplicity). A small first-fit `kmalloc` heap sits on top of PMM pages.
- No third-party kernel code, fonts, icons, wallpapers, sounds, or logos are
  included. The console uses the VGA ROM text glyphs (hardware, not embedded);
  future graphical work will use a to-be-designed original "Prism" typeface.
